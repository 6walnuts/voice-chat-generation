# voice-chat-generation · 录你自己的声音，训练你自己的中文语音模型

一条龙工具链：**采集你的语音（照稿朗读 + 自由说话）→ 一键导出训练集 →
微调开源模型（GPT-SoVITS）→ 输入任意文本，用你的声音说出来**。

录音、切分、导出零第三方依赖（纯浏览器 + Python 标准库），打开就能用；
训练用现成的开源项目，不需要从零训练模型——用你 5~25 分钟的录音去
微调一个预训练好的声音克隆模型，就能得到相当像你的效果。

## 两种采集模式（互补，建议都录）

| 模式 | 怎么录 | 优点 | 定位 |
|---|---|---|---|
| **照稿朗读** | 页面给句子，照着念 | 文本天然精确对齐；150 句语料保证发音覆盖 | 保底：至少录完 A 批（30 句，约 5 分钟） |
| **自由说话** | 不看稿随便聊 1~5 分钟，系统按停顿自动切段，你逐段校对文字 | 语气节奏是你**平时说话**的样子，不带朗读腔 | 增自然：再来 5~10 分钟，模型明显更像日常的你 |

朗读数据教会模型「你的发音」，自由说话数据教会模型「你说话的感觉」。
合成时参考音频选自由说话的段落，出来的就是聊天语气；选朗读段落，就是播报语气。

## 快速开始

**零安装版（推荐先用这个）**：下载 [`web/index.html`](web/index.html)
这一个文件，用 Chrome / Edge 双击打开即可——两种采集模式齐全，录音保存在
浏览器本地（IndexedDB，关页不丢），点「导出数据集」得到完整的训练集 zip
（wavs/ + meta.jsonl + gptsovits.list，可直接喂给 GPT-SoVITS）。
麦克风被拦时还能改用「导入音频文件」，把手机录音 m4a/mp3 导进来处理。

**完整版（Python 本地服务）**：

```bash
git clone https://github.com/6walnuts/voice-chat-generation.git
cd voice-chat-generation
python3 recorder/server.py
```

浏览器会自动打开 http://127.0.0.1:8380/ ：

**照稿朗读**：按批次展示 150 句（A 批优先）。**空格** 开始/停止录音，
试听满意按 **回车** 保存跳下一句，念错按 **R** 重录。随时关掉，下次自动续录。

**自由说话**：点「🗣 自由说话」标签 → 随便聊一段 → 停止后「上传并按停顿切分」→
逐段听音频、写下你实际说的字 → 确认入库（说废的段直接丢弃）。
想让语音识别先打草稿（可选）：

```bash
pip install faster-whisper                  # 唯一的可选依赖，本地运行
python3 scripts/transcribe_pending.py       # 草稿写回后刷新页面即见
```

录完（哪怕只录了 A 批）执行：

```bash
python3 scripts/export_dataset.py
```

会做质量体检（削波/过短/音量过小逐条提醒），并生成 GPT-SoVITS
可直接使用的标注文件 `dataset/gptsovits.list`。

最后按 **[docs/training.md](docs/training.md)** 的教程微调与合成
（需要一台带 NVIDIA 显卡的电脑或 Colab；也有不训练的零样本路线可先尝鲜）。
训练完成后可用命令行合成：

```bash
python3 scripts/tts_client.py "你好，这是用我自己的声音说的。" --ref dataset/wavs/A24.wav
```

## 目录结构

```
voice-chat-generation/
├── corpus/sentences.json    朗读语料：150 句 × 6 批（可自行增删）
│                              A 基础发音覆盖（声母/韵母/声调/儿化/变调）
│                              B 日常口语   C 疑问与感叹
│                              D 数字时间   E 叙述描写   F 长句
├── web/index.html           零安装单文件版：双击即用，数据存浏览器，导出 zip
├── recorder/                完整版录音采集（server.py + 网页，零依赖）
├── dataset/                 你的录音数据（自动生成，已 gitignore，注意备份！）
│   ├── wavs/                  朗读句 <句子ID>.wav + 自由说话切段 S###.wav
│   ├── raw/                   自由说话的原始长录音留档
│   ├── meta.jsonl             已入库条目的文本/时长等元数据
│   ├── pending.jsonl          自由说话待校对队列
│   └── gptsovits.list         导出的训练标注
├── scripts/
│   ├── export_dataset.py    导出 + 质量体检
│   ├── transcribe_pending.py 给待校对段做语音识别草稿（可选，faster-whisper）
│   └── tts_client.py        调用 GPT-SoVITS API 合成语音
└── docs/training.md         训练与合成完整教程
```

## 录音建议（直接影响最终效果）

- **环境**：越安静越好。底噪、回声、键盘声都会被模型「学」进你的声音里。
- **设备**：手机耳机麦 < 笔记本内置麦 < 独立 USB 麦克风。页面底部可切换输入设备。
- **姿势**：嘴离麦克风约一拳，保持距离一致；整个采集过程尽量同一设备同一环境。
- **朗读批**：自然念即可，不必播音腔；念错、卡顿就重录，别将就。
- **自由说话批**：就当在跟朋友发语音，说错也没关系——废段校对时丢弃就行。
  校对时写「说出来的字」：数字按读法写汉字（「二零二六」），语气词说了就写上。
- **数量**：A 批（约 3~5 分钟）即可开始训练；朗读 + 自由说话共 15~25 分钟效果明显更好。
- 页面已自动关闭浏览器的回声消除/降噪/自动增益，保留最原始的音色。

## 常见问题

- **必须在本机跑吗？** 浏览器只在 `localhost` / HTTPS 下开放麦克风，所以要在
  有麦克风的电脑上运行；想用远程服务器存数据可以 SSH 端口转发。
- **想换/加句子？** 直接编辑 `corpus/sentences.json`（id 别重复）。也可以让 AI
  按你的常用领域（如客服话术、游戏台词）再生成几批，追加进去。
- **自由说话切得不理想？** 原始长录音都留档在 `dataset/raw/`，不满意的段丢弃即可，
  数据不会丢；说话时句间稍作停顿（半秒），切分会更准。
- **数据在哪，会上传吗？** 全部在本地 `dataset/` 目录，不经过任何网络服务
  （可选的语音识别草稿也是本地模型）。这是你的原始资产，记得自己备份。

## 伦理与安全

请只用本工具采集**你自己**的声音，或已取得明确授权的声音；
不要将合成语音用于冒充他人、诈骗或任何误导性用途。
