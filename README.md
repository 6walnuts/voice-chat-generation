# voice-chat-generation · 录你自己的声音，训练你自己的中文语音模型

一条龙工具链：**生成朗读句子 → 浏览器逐句录音 → 一键导出训练集 →
微调开源模型（GPT-SoVITS）→ 输入任意文本，用你的声音朗读出来**。

录音和导出零第三方依赖（纯浏览器 + Python 标准库），打开就能用；
训练用现成的开源项目，不需要从零训练模型——用你 5~25 分钟的录音去
微调一个预训练好的声音克隆模型，就能得到相当像你的效果。

## 快速开始

```bash
git clone https://github.com/6walnuts/voice-chat-generation.git
cd voice-chat-generation
python3 recorder/server.py
```

浏览器会自动打开 http://127.0.0.1:8380/ ：

1. 页面按批次展示 150 个朗读句子（A 批是发音覆盖核心批，优先录）。
2. 按 **空格** 开始/停止录音，试听满意后按 **回车** 保存并跳到下一句，念错按 **R** 重录。
3. 随时可以关掉，下次启动自动接着上次的进度；已录的句子可重录覆盖。

录完（哪怕只录了 A 批）执行：

```bash
python3 scripts/export_dataset.py
```

会做质量体检（削波/过短/音量过小逐条提醒），并生成 GPT-SoVITS
可直接使用的标注文件 `dataset/gptsovits.list`。

最后按 **[docs/training.md](docs/training.md)** 的教程微调与合成
（需要一台带 NVIDIA 显卡的电脑或 Colab；也有不训练的零样本路线可先尝鲜）。
训练完成后可用命令行合成：

```bash
python3 scripts/tts_client.py "你好，这是用我自己的声音说的。" --ref dataset/wavs/A24.wav
```

## 目录结构

```
voice-chat-generation/
├── corpus/sentences.json    朗读语料：150 句 × 6 批（可自行增删）
│                              A 基础发音覆盖（声母/韵母/声调/儿化/变调）
│                              B 日常口语   C 疑问与感叹
│                              D 数字时间   E 叙述描写   F 长句
├── recorder/                录音采集（server.py + 网页，零依赖）
├── dataset/                 你的录音数据（自动生成，已 gitignore，注意备份！）
│   ├── wavs/<句子ID>.wav      48kHz 16-bit 单声道，自动掐头去尾静音
│   ├── meta.jsonl             每条录音的文本/时长/峰值等元数据
│   └── gptsovits.list         导出的训练标注
├── scripts/
│   ├── export_dataset.py    导出 + 质量体检
│   └── tts_client.py        调用 GPT-SoVITS API 合成语音
└── docs/training.md         训练与合成完整教程
```

## 录音建议（直接影响最终效果）

- **环境**：越安静越好。底噪、回声、键盘声都会被模型「学」进你的声音里。
- **设备**：手机耳机麦 < 笔记本内置麦 < 独立 USB 麦克风。页面底部可切换输入设备。
- **姿势**：嘴离麦克风约一拳，保持距离一致；整个采集过程尽量同一设备同一环境。
- **读法**：自然说话即可，不必播音腔；念错、卡顿就重录，别将就。
- **数量**：A 批（约 3~5 分钟）即可开始训练；全部录完（15~25 分钟）效果明显更好。
- 页面已自动关闭浏览器的回声消除/降噪/自动增益，保留最原始的音色。

## 常见问题

- **必须在本机跑吗？** 浏览器只在 `localhost` / HTTPS 下开放麦克风，所以要在
  有麦克风的电脑上运行；想用远程服务器存数据可以 SSH 端口转发。
- **想换/加句子？** 直接编辑 `corpus/sentences.json`（id 别重复）。也可以让 AI
  按你的常用领域（如客服话术、游戏台词）再生成几批，追加进去。
- **数据在哪，会上传吗？** 全部在本地 `dataset/` 目录，不经过任何网络服务。
  这也是你的原始资产，记得自己备份。

## 伦理与安全

请只用本工具采集**你自己**的声音，或已取得明确授权的声音；
不要将合成语音用于冒充他人、诈骗或任何误导性用途。
